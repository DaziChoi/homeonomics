Privacy Policy

Last updated: November 6, 2026

This policy covers the Homeonomics publishing tool (the "Tool"), an internal application the Homeonomics channel owner uses to manage the Homeonomics YouTube channel.

YouTube API Services

The Tool uses YouTube API Services. By using the Tool you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Who uses the Tool

The Tool is used only by the owner of the Homeonomics channel, signed in with their own Google account. It is not available to the public, and it does not sign in, access or collect data from any other user.

What data the Tool accesses

  • Upload videos, thumbnails, titles, descriptions and tags to the Homeonomics channel, and schedule their publication.
  • Read basic information about the Homeonomics channel and its own videos.
  • Read the Homeonomics channel's own YouTube Analytics reports (for example views and watch time) to plan future videos.

The Tool does not access other channels' private data or any viewer's personal information.

How data is stored and shared

  • The Google sign-in token and analytics reports are stored only on the channel owner's own computer.
  • No data obtained through the YouTube API Services is sold, shared with third parties, or used for advertising.
  • The Tool does not use cookies and does not store data in a viewer's browser.
  • Analytics data is kept no longer than needed for planning, and is refreshed or deleted at least every 30 days.

Revoking access

Access granted to the Tool can be revoked at any time from the Google security settings page. Revoking access deletes the Tool's ability to use the account; locally stored data can be deleted on request.

Contact

Questions about this policy can be sent through the Homeonomics YouTube channel.
